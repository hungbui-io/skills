## What it does

`literature-review` conducts systematic, scoping, and narrative literature reviews using PubMed, arXiv, bioRxiv, Semantic Scholar, and other appropriate sources

House boundary: a primary-source note for a software or API question is research. This skill runs a scientific literature review.
