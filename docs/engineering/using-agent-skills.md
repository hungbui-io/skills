## What it does

`using-agent-skills` is the phase map for the vendored engineering lifecycle: from an underspecified ask, through a spec, a plan, a build, and a launch.

The defining constraint is that the house router is ask-matt, and only you can open this map. It does not run at the start of a session. When a row names a model-invoked skill, the next step is one Skill tool call. The two user-invoked rows (`interview-me` and `test-driven-development`) are something you type.

## When to reach for it

You invoke this by typing `/using-agent-skills`, and the [agent](https://www.aihero.dev/ai-coding-dictionary/agent) won't reach for it on its own.

| Your situation | Reach for |
| --- | --- |
| You want the vendored phase list | This skill, which you type |
| You want the router for the whole set | [ask-matt](https://aihero.dev/skills-ask-matt) |

## A phase list

The leading words are **phase list**. The map is a tree of situations, and each leaf is one skill. It is a menu. It is not permission to run every skill on the tree.

## Common questions

**How is this different from ask-matt?**

[ask-matt](https://aihero.dev/skills-ask-matt) routes the whole set, including this lifecycle, and it picks the house skill when both could apply. This page is only the vendored phase list, and you open it yourself.

## It's working if

- It names one next skill and stops.
- It does not start the work, and it does not appear on its own at session start.

## Where it fits

This is a **standalone router** for the vendored lifecycle only. The router over the whole set is ask-matt.

Its neighbour is [ask-matt](https://aihero.dev/skills-ask-matt), because both answer which skill is next, and the house router wins when you did not ask for this map.

When you are unsure which skill fits, [ask-matt](https://aihero.dev/skills-ask-matt) routes you.
