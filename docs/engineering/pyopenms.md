## What it does

`pyopenms` processes mass spectrometry data with pyOpenMS. Supports proteomics and metabolomics workflows: feature detection, peptide/protein identification, label-free quantification, adduct/accurate-mass annotation, and complex LC-MS/MS pipelines. Supports extensive file formats and algorithms. For simple spectral comparison and small-molecule library matching use matchms.
