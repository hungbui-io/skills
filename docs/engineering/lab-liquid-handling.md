## What it does

`lab-liquid-handling` authors and reviews liquid-handling protocols for Opentrons and PyLabRobot.

A physical robot run stays behind the operator. The skill prepares, simulates, and reviews the protocol.

## When to reach for it

Type `/lab-liquid-handling`, or the [agent](https://www.aihero.dev/ai-coding-dictionary/agent) reaches for it when a task fits.

Reach for this when the task is an Opentrons Protocol API v2 protocol or a PyLabRobot liquid-handling plan.

## Protocols

The leading word is **protocol**. Opentrons procedures and PyLabRobot procedures live in this skill, and neither runs hardware on its own.

## It's working if

- You can name the robot API the protocol targets.
- A physical run is still waiting for the operator.
